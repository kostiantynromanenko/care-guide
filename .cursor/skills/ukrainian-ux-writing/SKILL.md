# Ukrainian UX Writing Skill

## Purpose

Use this skill for all user-facing text.

## Language rule

Ukrainian is the primary and default language of the website.

Use Ukrainian for:

- navigation;
- headings;
- buttons;
- forms;
- hints;
- validation;
- empty states;
- errors;
- metadata;
- SEO copy;
- accessibility labels;
- affiliate notices;
- demo content.

English is allowed only for code identifiers and developer-facing technical text.

## Tone

Write in a tone that is:

- calm;
- clear;
- useful;
- respectful;
- non-aggressive;
- easy to scan.

## Avoid

- literal translations from English;
- Russian calques;
- bureaucratic wording;
- excessive exclamation marks;
- artificial urgency;
- exaggerated promises;
- medical claims;
- manipulative sales copy;
- vague phrases such as `найкращий для всіх`.

## Button guidance

Prefer clear actions:

- `Підібрати догляд`
- `Переглянути добірку`
- `Дізнатися більше`
- `Перейти до товару`
- `Переглянути на офіційному сайті`

Avoid:

- `Купити зараз` when the site does not sell;
- `Замовити у нас`;
- misleading checkout wording.

## Content rules

- Explain one idea per sentence.
- Prefer short paragraphs.
- Use consistent terminology.
- Do not call informational recommendations professional diagnosis.
- Mark demo content as demo when necessary.
- Keep affiliate disclosure understandable.

## Review checklist

- natural Ukrainian;
- no mixed-language UI;
- consistent terms;
- clear external actions;
- no unsupported claims;
- useful alt text;
- Ukrainian validation and error messages.

## Approval boundary

Legal, medical, affiliate, or brand-sensitive wording must be flagged for approval.
