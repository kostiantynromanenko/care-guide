# First Design Task for Cursor Agent

## Objective

Prepare three clearly different homepage design directions using the same structure and demo content.

Do not implement all three as full production pages immediately.

## Phase 1: Proposal only

Present three options:

### Option A: Editorial Natural

Possible traits:

- warm neutral palette;
- restrained serif headings;
- large lifestyle imagery;
- magazine-like spacing;
- calm premium feeling.

### Option B: Clean Care Assistant

Possible traits:

- modern sans-serif typography;
- clear cards and filters;
- service-oriented interface;
- strong hierarchy;
- highly practical mobile UX.

### Option C: Soft Botanical

Possible traits:

- muted natural accents;
- organic shapes used sparingly;
- soft cards;
- friendly and approachable tone;
- gentle beauty aesthetic.

For every option include:

- short description;
- color tokens;
- typography suggestion;
- hero structure;
- card style;
- CTA style;
- mobile behavior;
- strengths;
- possible risks.

Then stop and request approval.

## Phase 2: Approved prototype

After explicit approval:

1. implement only the approved homepage direction;
2. use demo content;
3. create reusable components;
4. include mobile and desktop layouts;
5. do not add CMS;
6. do not implement other pages yet;
7. provide a concise change summary;
8. ask for approval before continuing to inner pages.

## Phase 3: Inner-page extension

Only after homepage approval, propose the next order:

1. collection detail;
2. care selector;
3. collection listing;
4. article page;
5. about page.

Do not implement them all in one step unless explicitly approved.
